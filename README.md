# ریتم

## طراحی نسخهٔ بعدی

کاربر روز اول یک فرم کوتاه تکمیل می‌کند، ورزش اصلی‌اش را انتخاب می‌کند و همان روز برنامهٔ هفت‌روزه می‌گیرد. می‌تواند تغییرهای ایجنت را پیش از اعمال ببیند و تأیید کند. ترجیحات و بازخورد کوتاه روی جلسه‌های پیشنهادی، برنامهٔ هفته‌های بعد را بهتر با روتینش هماهنگ می‌کنند.

- [داستان‌های کاربر و معیارهای پذیرش](docs/USER_STORIES.md)
- [الگوی داده و ایندکس‌های MongoDB](docs/DATABASE_PATTERN.md)
- [نقشهٔ توسعه برای Django، React و اندروید](docs/DEVELOPMENT_ROADMAP.md)

## اجرای نمونهٔ محلی فعلی

نمونهٔ JavaScript در این پوشه جریان قبلی دفتر تمرین را نشان می‌دهد. دستور اجرا و بخش‌های بعدی مربوط به همان نمونه‌اند.

با Node.js 22.15 یا بالاتر، از پوشهٔ پروژه اجرا کن. پروژه وابستگی جانبی ندارد.

```powershell
npm.cmd start
```

در مرورگر [ریتم](http://127.0.0.1:4173/) را باز کن. داده‌های دفتر در همان مرورگر و همان آدرس ذخیره می‌شوند.

## جریان استفاده از نمونهٔ محلی

1. ورزش اصلی، رشته‌های مکمل و روزهای آزاد را انتخاب کن. اگر از قبل سابقهٔ تمرین داری، می‌توانی تاریخ شروع دوره را تنظیم کنی.
2. جلسه‌ها را دستی ثبت کن یا در «ورود اطلاعات» فایل ZIP یا XML اپل یا فایل `activities.csv` استراوا را وارد کن. فایل در مرورگر خوانده می‌شود و مختصات، داده‌های زیستی و یادداشت‌های فایل ذخیره نمی‌شوند. ورود دوبارهٔ یک رکورد از همان منبع آن را تکرار نمی‌کند.
3. از روز سی‌ام، با حداقل چهار جلسه در سه روز متفاوت و دو جلسه از ورزش اصلی در بازهٔ اخیر، برنامهٔ هفت روز بعد آماده می‌شود. برنامه مدت و شدت پیشنهادی، هدف هر جلسه و روزهای استراحت را نشان می‌دهد. «دیدن برنامهٔ نمونه» برای مرور فوری در دسترس است.

راهنمای خروجی‌گیری از [Apple Health](https://support.apple.com/en-euro/guide/iphone/iph5ede58c3d/ios) و [Strava](https://support.strava.com/hc/en-us/articles/216918437-Exporting-your-Data-and-Bulk-Export). ورود این نسخه فایل‌محور است. سیاست API استراوا برای پردازش داده‌های API در کاربردهای هوش مصنوعی محدودیت دارد. [سیاست API استراوا](https://www.strava.com/legal/api_policy)

## مربی هوش مصنوعی در نمونهٔ محلی

برای فعال کردن مسیر اختیاری مربی، `.env.example` را به `.env` کپی کن، `OPENAI_API_KEY` و `OPENAI_MODEL` را تنظیم کن و سرور را دوباره اجرا کن. مدل انتخابی باید از Structured Outputs در Responses API پشتیبانی کند. [راهنمای OpenAI](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)

دکمهٔ دریافت پیشنهاد، رشته‌های انتخابی و خلاصهٔ تمرین‌های دستی ۳۰ روز اخیر را به OpenAI می‌فرستد. خلاصه شامل رشته، مدت، شدت و فاصلهٔ زمانی جلسه است. عامل اول الگوی تمرین را استخراج می‌کند و عامل دوم برای ورزش اصلی و مکمل تمرکز پیشنهادی می‌نویسد. برنامه‌ریز محلی با داده‌های دفتر کار می‌کند و برای ساخت برنامه به کلید API نیاز ندارد.
